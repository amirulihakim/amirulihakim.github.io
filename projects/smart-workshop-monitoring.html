Smart Workshop Monitoring

A low-cost ESP32 monitoring platform planned around MQTT transport, SQL history, event logging, dashboard visualization, and automated analysis.

CONDITION MONITORING

Goal

The goal is to build a workshop monitoring platform that can collect equipment or environment signals, log events, store historical readings, and make the data useful through dashboards and automated analysis.

Planned Approach

  • Use ESP32-based nodes for affordable sensor acquisition.
  • Send readings through MQTT for lightweight data transport.
  • Store readings and events in a SQL historian.
  • Build a dashboard that supports live status, trends, and maintenance signals.

Portfolio Value

This project extends the industrial monitoring experience into a personal build that can demonstrate prototyping, data architecture, and practical condition-monitoring logic.
